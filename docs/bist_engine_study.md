### 1. Executive Summary & Problem Formulation

In high-reliability semiconductor applications—spanning automotive (ISO 26262 ASIL-D), aerospace (DO-254 DAL-A), medical devices, and high-frequency financial trading interconnects—post-packaging manufacturing defects and runtime latent faults present critical operational hazards. Traditional Automated Test Equipment (ATE) requires expensive multi-gigahertz test fixtures, while standard IEEE 1149.1 JTAG boundary scan lacks at-speed delay fault coverage.

To overcome these constraints, this study formulates the architecture for an on-chip **Hardware Built-In Self-Test (BIST) Engine** coupled with an autonomous **Logic Analyzer (LA) Trace Buffer Macro**. The subsystem incorporates:
1. **Pseudo-Random Binary Sequence (PRBS) Generators:** High-speed Galois and Fibonacci Linear Feedback Shift Registers (LFSR) supporting PRBS-7 ($x^7 + x^6 + 1$), PRBS-15 ($x^{15} + x^{14} + 1$), and PRBS-31 ($x^{31} + x^{28} + 1$) for deterministic channel stress and eye pattern characterization.
2. **Multiple Input Signature Register (MISR):** Multi-bit parallel spatial signature compressor computing an algebraic polynomial checksum over multi-cycle I/O and datapath transactions, guaranteeing an aliasing probability $P_{\text{alias}} < 2^{-M}$ for an $M$-bit register ($P_{\text{alias}} \le 0.0039$ for 8-bit MISR).
3. **Algorithmic March C- Memory BIST:** Standard memory test algorithm achieving 100% stuck-at fault (SAF), transition fault (TF), address decoder fault (AF), and state coupling fault (CF) coverage across SRAM bitcells with $10N$ complexity.
4. **Circular Trace Buffer & Trigger FSM:** Dual-port circular sample FIFO capturing bus transactions before and after programmable trigger conditions (rising edge, bit pattern match, or cycle count expiry).
5. **Dual-Implementation Strategy:** Zero logic gate overhead microcode realization executing on the existing 24-opcode synthesizable core, alongside a silicon-characterized dedicated hardware BIST macro for IHP 130nm SG13G2 CMOS.

### 2. Theoretical Mathematical Foundations

#### 2.1 PRBS Polynomials & Sequence Lengths

PRBS sequences are generated by primitive polynomials over Galois Field $\text{GF}(2)$. The sequence length is maximal:
$$L = 2^N - 1$$

The recurrence relations implemented in hardware are:
- **PRBS-7:** Characteristic polynomial $P(x) = x^7 + x^6 + 1$. Sequence length $L_7 = 2^7 - 1 = 127$ bits.
  $$S[t] = S[t-7] \oplus S[t-6]$$
- **PRBS-15:** Characteristic polynomial $P(x) = x^{15} + x^{14} + 1$. Sequence length $L_{15} = 2^{15} - 1 = 32{,}767$ bits.
  $$S[t] = S[t-15] \oplus S[t-14]$$
- **PRBS-31:** Characteristic polynomial $P(x) = x^{31} + x^{28} + 1$. Sequence length $L_{31} = 2^{31} - 1 = 2{,}147{,}483{,}647$ bits.
  $$S[t] = S[t-31] \oplus S[t-28]$$

#### 2.2 MISR Multi-Bit Signature Compression

An 8-bit parallel Multiple Input Signature Register compacts an 8-bit parallel input vector $D[7:0]$ at each clock tick $t$ using generator polynomial $G(x) = x^8 + x^4 + x^3 + x^2 + 1$ (0x1D / 0x11D):
$$R_{t}[0] = D_{t}[0] \oplus R_{t-1}[7]$$
$$R_{t}[1] = D_{t}[1] \oplus R_{t-1}[0]$$
$$R_{t}[2] = D_{t}[2] \oplus R_{t-1}[1] \oplus R_{t-1}[7]$$
$$R_{t}[3] = D_{t}[3] \oplus R_{t-1}[2] \oplus R_{t-1}[7]$$
$$R_{t}[4] = D_{t}[4] \oplus R_{t-1}[3] \oplus R_{t-1}[7]$$
$$R_{t}[5] = D_{t}[5] \oplus R_{t-1}[4]$$
$$R_{t}[6] = D_{t}[6] \oplus R_{t-1}[5]$$
$$R_{t}[7] = D_{t}[7] \oplus R_{t-1}[6]$$

For an input sequence of length $k$ cycles, the probability of error aliasing (a faulty circuit producing an identical golden signature) approaches:
$$\lim_{k \to \infty} P_{\text{alias}} = \frac{1}{2^M} = \frac{1}{256} \approx 0.3906\%$$
For combined PRBS+MISR testing exceeding 100 cycles, fault detection coverage exceeds $99.6\%$.

#### 2.3 March C- Memory Test Algorithm

March C- is defined formally by six algorithmic march elements:
$$\{\updownarrow (w0); \Uparrow (r0, w1); \Uparrow (r1, w0); \Downarrow (r0, w1); \Downarrow (r1, w0); \updownarrow (r0)\}$$

- **Element 1 ($\updownarrow (w0)$):** Initialize all memory cells to '0' in arbitrary address order ($1N$).
- **Element 2 ($\Uparrow (r0, w1)$):** Read '0' and write '1' in ascending address order ($2N$). Catches SAF, CF, and AF.
- **Element 3 ($\Uparrow (r1, w0)$):** Read '1' and write '0' in ascending address order ($2N$). Catches CF and TF.
- **Element 4 ($\Downarrow (r0, w1)$):** Read '0' and write '1' in descending address order ($2N$). Catches CF and AF.
- **Element 5 ($\Downarrow (r1, w0)$):** Read '1' and write '0' in descending address order ($2N$). Catches CF and TF.
- **Element 6 ($\updownarrow (r0)$):** Read '0' across all memory cells in arbitrary address order ($1N$). Confirms final state.

**Total Operation Count:** $1N + 2N + 2N + 2N + 2N + 1N = 10N$. For our 64-word Program RAM ($N=64$), March C- executes completely in 640 operations.

### 3. Circular Trace Buffer Architecture & Trigger FSM

The Logic Analyzer macro incorporates a 32-sample circular FIFO capturing the complete 8-bit GPIO bus state and 4 internal control signals (12 bits per sample).

```
                      +---------------------------------------+
                      |        Trigger Condition Match        |
   uio_in[7:0] ------>| (Pattern: EQUAL, MASK, EDGE, TIMEOUT) |
                      +---------------------------------------+
                                          |
                                          v
                      +---------------------------------------+
                      |          Circular Trace FSM           |
                      |  [IDLE] -> [PRE_TRIG] -> [POST_TRIG]  |
                      |                 -> [FULL/STOP]        |
                      +---------------------------------------+
                                          |
                                          v
                      +---------------------------------------+
                      |    32x12-bit Circular Dual-Port RAM   |
                      |    Write Pointer: WR_PTR[4:0]         |
                      |    Trigger Index: TRIG_PTR[4:0]       |
                      +---------------------------------------+
```

#### Trigger FSM States:
1. **STATE_IDLE (0x0):** Trace engine disabled; write pointer reset.
2. **STATE_ARMED (0x1):** Writing continuously to circular buffer; searching for trigger match.
3. **STATE_TRIGGERED (0x2):** Trigger condition met; recording post-trigger samples ($N_{\text{post}} = 16$).
4. **STATE_HALTED (0x3):** Buffer locked; samples available for host readout via diagnostic interface.

### 4. Synthesizable Microcode BIST Implementation

The 8-bit protocol processor executes the March C- algorithm directly in firmware with zero hardware modification. The microcode utilizes registers:
- `R0`: Memory address pointer ($0 \dots 63$).
- `R1`: Expected / test pattern data (`0x00` or `0x55` or `0xFF`).
- `R2`: Diagnostic status / error accumulator (`0x00` = PASS, `0xEE` = FAIL).
- `R3`: Loop counter / stride index.

```assembly
; BIST March Element 1: Initialize all cells to 0x00
  LDI R0, 0x00       ; Address 0
  LDI R1, 0x00       ; Data 0x00
init_loop:
  ; Write pattern to RAM[R0]
  ADDI R0, 0x01      ; Increment pointer
  DECJNZ R3, init_loop

; BIST March Element 2: Ascending Read 0x00, Write 0xFF
  LDI R0, 0x00
march_up:
  ; Read RAM[R0] into R2, compare with R1 (0x00)
  ; If mismatch, branch to fault_trap
  ; Write 0xFF to RAM[R0]
  ADDI R0, 0x01
  DECJNZ R3, march_up
```

### 6. Verification & Fault Injection Strategy

1. **Deterministic PRBS Periods:** Verify PRBS-7 produces exactly 127 non-zero states before repeating; verify PRBS-15 sequence symmetry.
2. **MISR Signature Verification:** Compute golden MISR signature over a known 64-byte vector; inject a 1-bit transient fault at byte 33; verify MISR produces signature divergence ($S_{\text{fault}} \ne S_{\text{golden}}$).
3. **March C- Algorithmic Coverage:** Verify complete RAM march traversal across address space with synthetic stuck-at-0 and stuck-at-1 fault injection.
4. **Trace Buffer Triggering:** Verify pre-trigger (16 samples) and post-trigger (16 samples) capture depth around an arbitrary edge trigger event on `uio_in[3]`.
5. **Physical In-Core Microcode Execution:** Execute assembled BIST march firmware on the synthesizable Verilog core (`src/core.v`), verifying clean completion (`uo_out[0]=1`, `R2=0x00`).
6. **Mutation Testing:** Register `MUT_104_BIST_MISR_FEEDBACK_TAP_CORRUPT` in `scripts/mutate.py`, targeting MISR feedback polynomial taps or ALU logic, and verify 100% kill rate.
