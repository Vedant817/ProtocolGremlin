# Verification strategy

Status: v0 bootstrap. This documents what verification exists today and
what's queued next; see `PROJECT_MASTER_PLAN.md` section 8 for the full
long-term strategy (unit tests per block, firmware-level protocol tests,
randomized/constrained tests, formal, gate-level, differential, mutation
testing).

## What exists now: differential testing

`test/test.py` is a cocotb testbench that:

1. Assembles `firmware/loop_demo.asm` with `tools/assembler.py`.
2. Runs the resulting program through `tools/isa_model.py`
   (`CoreModel`), an independently written, cycle-accurate Python
   interpreter of ISA v0.
3. Runs the *same* program on the RTL (`src/core.v` via `src/project.v`
   through the Tiny Tapeout `tb.v` wrapper), stepping one clock cycle at a
   time.
4. After every single clock cycle, asserts that the RTL and the Python
   model agree on: `pc`, `r0`-`r3`, the `z` flag, `halted`, and the
   externally observable `uio_oe`/`uio_out` pins.

This is deliberately a whitebox test: it reaches into `core`'s internal
registers via cocotb's hierarchical signal access
(`dut.user_project.u_core.<signal>`) rather than adding debug ports to the
fixed Tiny Tapeout pinout. See `src/core.v`'s header comment.

Two independently written implementations of the same spec (`docs/isa.md`)
agreeing on every single cycle of a program that exercises 15 of the 19
opcodes is meaningfully stronger evidence than either "the RTL simulation
doesn't crash" or "the Python model looks right" alone. If the RTL and
model ever disagree, that's a genuine bug in one of them (or in the shared
spec understanding) - not a flaky test.


## Verification Layers

Verification in this project is multi-tiered, adhering to the principle that
model confidence is never evidence:

### 1. SymbiYosys Formal Verification (`formal/core.sby`)
Using the PVFI (Protocol-engine Verification Formal Interface) and Z3 SMT solver,
the design formally proves:
- **Reset convergence:** All architectural registers, PC, flags, and FSM states initialize to exact known values upon reset release.
- **PC safety & range:** PC is strictly bounded within the physical memory space across all possible execution paths.
- **WAIT deterministic countdown:** Active `WAIT` sequences strictly decrement by 1 each clock cycle until termination; PC is strictly held.
- **Halt permanence:** Once `halted`, the core never un-halts, and internal registers remain stable indefinitely.
- **Cycle counter monotonicity:** The free-running counter strictly increments by 1 on every clock cycle.
- **Bootloader FSM absorbency:** Once execution reaches `LD_DONE`, it never re-enters bootloading state.
- **PVFI interface correctness:** Retirement ordering, PC writeback, and instruction validity conform to the formal retirement protocol.

### 2. Cycle-by-Cycle Differential Verification (`test/test.py`, `test/test_waitedge.py`)
Executes programs on RTL and simultaneously on `tools/isa_model.py` (`CoreModel`),
asserting cycle-by-cycle equality across PC, registers R0–R3, Z flag, halted status,
and GPIO direction/output registers.

### 3. Independent Protocol Verification (`test/test_uart.py`)
Bit-banged UART TX firmware generated by `tools/uart_model.py` is verified against
an asynchronous, independent software UART receiver (`UartReceiver`) across edge
cases (`0x00`, `0xFF`, `0x55`, `0xAA`) and pseudorandom bytes at multiple bit periods
(4, 8, 16 cycles/bit), with fresh reset and bootload cycles.

### 4. Per-Opcode Isolated Unit Tests (`test/test_opcodes.py`)
Dedicated unit tests exercising every ALU operation, conditional branch, loop
construct, GPIO bus direction, and bit-serial shift in isolation.

### 5. Hardware Timing Discovery Verification (`test/test_waitedge.py`)
Verifies single-cycle pulse width measurement and timestamp capture on unknown
external protocol signals via `WAITEDGE`.

## Running the Verification Suite

```bash
bash scripts/setup_env.sh   # one-time toolchain install (see docs/toolchain.md)
bash scripts/regress.sh     # runs the complete cocotb regression suite (9 tests)
sby -f formal/core.sby      # runs the SymbiYosys formal proof with Z3
```
